# Domain modules

The approved domain boundaries and their acceptance criteria are defined in [EXAMGEN AI Skill Plan](../docs/EXAMGEN_AI_SKILL_PLAN.md).

Planned independently testable domains:

- academic-ingestion
- subject-intelligence
- visual-intelligence
- blueprint-engine
- question-bank
- answer-and-rubric-intelligence
- moderation-and-quality
- examination-publisher
- attempt-management
- marking-engine
- performance-analytics
- revision-intelligence
- pdf-production
- administration-and-governance

The current release only delivers the initial question-generation API and student examination workspace. These domains are roadmap items until implemented and tested. Python is the approved authoritative backend; the current TypeScript Worker is transitional and must not become a competing source of truth.

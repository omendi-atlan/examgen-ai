# Roadmap

1. Foundation: responsive student UI, sample assessment, validated AI generation endpoint, Docker and CI.
2. Accounts and data: authentication, profiles, database schema, student examination history.
3. Content intelligence: PDF/document ingestion, source citations, topic extraction and examination blueprints.
4. Assessment engine: richer question types, question banks, moderation and rubric-based marking.
5. Visual intelligence: identify visual requirements, generate diagrams, require approval, attach approved assets to exam items.
6. Learning intelligence: adaptive difficulty, error analysis, personalised revision plans and spaced retrieval.
7. Deliverables: exam PDFs, answer keys, examiner notes and student revision PDFs.
8. Production: security review, accessibility, load tests, monitoring, backups and self-hosted deployment hardening.

Each phase requires tests, documented acceptance criteria and review before release.
